# The Video_Processor (app/processors/video_processor.py) shells out to the
# `ffmpeg` and `ffprobe` command-line binaries for media probing, audio
# extraction, and keyframe extraction. These are NOT Python packages and
# cannot be installed via pip -- install them via your OS package manager:
#   Debian/Ubuntu: apt-get install ffmpeg
#   macOS:         brew install ffmpeg
#   Windows:       https://ffmpeg.org/download.html (add the bin/ dir to PATH)
# VideoProcessor.process() raises a clear RuntimeError naming any missing
# binary rather than failing with an opaque error if these aren't on PATH.

# Phase 2C-R (secure file_url retrieval), CORRECTED: `urllib3` used
# directly rather than `requests`. The initial version used `requests`
# with a process-global monkeypatch of
# `urllib3.util.connection.create_connection` for IP pinning -- an audit
# correctly identified this as unsafe under concurrent requests (shared
# mutable global state). The corrected design constructs a fresh,
# request-local `urllib3.HTTPConnectionPool`/`HTTPSConnectionPool` per
# call, with the validated IP passed directly as that pool's own `host`
# argument -- no global state, no monkeypatching, safe under concurrency
# by construction (each call's pool is local to its own stack frame).
# `urllib3` was already present transitively (it underlies `requests`,
# which many other dependencies pull in); it is now the sole, explicit,
# directly-used HTTP layer for this one feature -- see
# app/pipeline/remote_source_resolver.py.
urllib3
